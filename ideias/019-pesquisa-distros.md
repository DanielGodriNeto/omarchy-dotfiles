# Pesquisa de distros e rices para inspirar o visual

- **Estado:** Em andamento
- **Origem:** pedido do usuário (13/11/2026)
- **Resumo:** Manter o Omarchy/Hyprland, mas puxar o visual para algo mais macOS-like, fluido e clean. Pesquisar distros (elementary OS, Deepin, COSMIC, Zorin, GNOME, KDE, Bazzite, NixOS), rices de Hyprland/Quickshell e componentes avulsos, e anotar tudo no projeto para não precisar reexplicar.

## Método
- Sem ISOs (vários GB, configs inacessíveis sem bootar). Clones rasos dos repositórios-fonte em pasta temporária, só leitura, nada executado: elementary (gala, dock, stylesheet, switchboard, notifications), Deepin control-center, COSMIC comp, end-4/dots-hyprland, Caelestia, Noctalia, Vicinae, WhiteSur.
- Três frentes de pesquisa: A distros, B rices Hyprland, C componentes avulsos.
- Toda afirmação marcada [verificado: fonte] ou [não verificado].
